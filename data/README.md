# Data source and synthetic generation

`data/sales.csv` is a reproducible synthetic commercial transaction dataset generated by `python -m src.generate_data` with fixed seed `20260820`.

The generator models commercial mechanisms rather than predetermined analytical conclusions:

- product-specific demand weights and modest monthly demand trends;
- two years of common and category-specific seasonality;
- regional demand and logistics-cost differences;
- channel-specific pricing, demand, and discount norms;
- segment-specific order sizes and negotiated discount expectations;
- gradual cost inflation;
- independent market-price, logistics, discount, and demand noise;
- rare seeded stochastic demand shocks to create realistic tail behavior.

No product, region, or channel is forced to be the analytical winner. The dashboard's conclusions are calculated from the generated transactions.

## Data dictionary

| Column | Meaning |
|---|---|
| `transaction_id` | Unique transaction-line identifier |
| `order_id` | Commercial order identifier; may span multiple lines |
| `order_date` | ISO order date |
| `region` | North, South, East, West |
| `channel` | Online, Retail, Distributor |
| `customer_segment` | Consumer, SMB, Mid-Market, Enterprise |
| `category` | Product category |
| `product` | Product name |
| `quantity` | Positive integer units |
| `list_price` | Unit list price before discount |
| `discount_rate` | Realized discount as a fraction from 0 to 1 |
| `unit_cost` | Unit commercial cost |
